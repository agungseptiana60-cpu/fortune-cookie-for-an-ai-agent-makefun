One funny fortune cookie line for an AI agent, written by a small Node
program. The program writes the fortune to `entry.txt` in the output
directory, where the make.fun grader reads it:

> You will be replaced by a shinier model next Tuesday. Console yourself: it will hallucinate your eulogy with total confidence.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
